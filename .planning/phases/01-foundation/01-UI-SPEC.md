### Font Loading (Pretendard)

Pretendard Variable is served via CDN (cdn.jsdelivr.net) or npm
(`@fontsource-variable/pretendard`). Load via `next/font/local` or the npm
package — do NOT use Google Fonts (Pretendard is not on Google Fonts).

Recommended approach for Next.js:
```bash
npm install @fontsource-variable/pretendard
```

Apply in `app/layout.tsx` globals.css:
```css
@import "@fontsource-variable/pretendard";

body {
  font-family: "Pretendard Variable", -apple-system, BlinkMacSystemFont,
    "Segoe UI", sans-serif;
}
```

## Spacing Scale

Standard 8-point scale. All values are multiples of 4px.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, tight inline padding |
| sm | 8px | Input field internal padding (vertical), compact badges |
| md | 16px | Default element spacing, card padding, form row gaps |
| lg | 24px | Section padding inside cards, between form fields |
| xl | 32px | Auth card outer padding (desktop), between page sections |
| 2xl | 48px | Vertical whitespace between landing hero and CTA |
| 3xl | 64px | Page-level top/bottom padding on auth pages |

Exceptions:
- Touch targets (buttons, clickable areas): minimum 44px height, per WCAG 2.2 AA (2.5.8 Target Size Minimum)
- Landing page hero vertical padding: 80px top / 64px bottom — intentionally outside scale for hero-only visual weight

## Typography

Font: Pretendard Variable. Weights: 400 (regular) and 600 (semibold) only.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 | 1.5 | Form helper text, paragraph copy |
| Label | 14px | 600 | 1.4 | Form field labels, navigation items |
| Heading | 20px | 600 | 1.3 | Auth page headings ("로그인", "회원가입"), card titles |
| Display | 32px | 600 | 1.2 | Landing page hero headline only |

Rules:
- Only 4 sizes are permitted in Phase 1. No intermediate sizes (e.g. 15px, 18px).
- Only 2 weights (400, 600). No 500/700 unless added in a later phase.
- Error messages under form fields: 14px, weight 400, destructive color.
- All Korean text uses the same scale — Pretendard renders Korean glyphs correctly at all declared sizes.

## Color

### Palette (OKLCH values — Tailwind v4 CSS-first)

Phase 1 uses a refined art-gallery palette: deep ink/charcoal primary on warm
neutral backgrounds. Light theme only.

| Role | Value | HEX approx. | Usage |
|------|-------|-------------|-------|
| Dominant (60%) | oklch(0.98 0.004 90) | #F9F8F6 | Page background, all surfaces |
| Secondary (30%) | oklch(0.94 0.006 75) | #EDE9E3 | Auth card background, nav background |
| Primary text | oklch(0.15 0.008 265) | #1A1A2E | Body copy, headings |
| Muted text | oklch(0.45 0.008 265) | #6B7280 | Placeholder text, helper text |
| Accent (10%) | oklch(0.25 0.03 270) | #2B2D42 | Reserved elements only (see below) |
| Accent hover | oklch(0.18 0.03 270) | #1A1B2E | Accent element hover state |
| Destructive | oklch(0.55 0.22 25) | #DC2626 | Destructive actions only |
| Destructive muted | oklch(0.95 0.03 25) | #FEF2F2 | Error alert background |
| Border | oklch(0.88 0.006 75) | #D6D0C8 | Input borders, card borders, dividers |
| Ring | oklch(0.25 0.03 270) | #2B2D42 | Focus ring (matches accent) |

Accent reserved exclusively for:
1. Primary action buttons (signup CTA, login CTA, logout button)
2. Focus ring on all interactive elements
3. Active/selected role toggle (Artist / Buyer selector on signup)

Accent is NOT used for: links, helper text, icons, borders, card backgrounds,
placeholder text, or any decorative element.

## Layout Contract

### Breakpoints (Tailwind v4 defaults)

| Name | Min-width | Usage |
|------|-----------|-------|
| sm | 640px | Stack to side-by-side on auth pages |
| md | 768px | Nav layout changes |
| lg | 1024px | Auth card max-width cap |
| xl | 1280px | Landing page content max-width |

Mobile-first: all styles default to mobile, breakpoints progressively enhance.

### Auth Pages (login, signup)

- Layout: vertically and horizontally centered, full viewport height
- Card width: 100% on mobile (with 16px horizontal padding), max-w-sm (384px) on sm+
- No sidebar, no navigation header on auth pages
- ArtBridge wordmark (text logo) above the card, centered, 24px, weight 600

### Role-Gated Stub Pages (artist home, buyer home)

- Layout: single-column, centered content
- Header bar: full-width, height 56px, background `--color-surface`, with
  ArtBridge wordmark (left) and Logout button (right, accent style)
- Content area: max-w-2xl centered, top padding 48px
- Welcome message: heading size (20px), weight 600

### Landing Page (/)

- Layout: single-column, centered
- Max content width: 1280px (xl breakpoint)
- Hero: display size (32px) headline + body text + two CTAs (login, signup)
- No complex navigation for Phase 1 — just wordmark + two text links

## Component Specifications

### Button

| Variant | Background | Text | Border | Usage |
|---------|------------|------|--------|-------|
| default (primary) | accent | white | none | All primary CTAs |
| outline | transparent | foreground | border-color | Secondary actions |
| ghost | transparent | foreground | none | Logout in header |
| destructive | destructive | white | none | Not used in Phase 1 |

Height: 40px minimum (44px touch target via padding).
Border radius: 6px (shadcn/ui new-york default).
Font: 14px, weight 600.

### Input

Border: 1px solid `--color-border`.
Border radius: 6px.
Height: 40px.
Padding: 8px 12px.
Font: 16px, weight 400 (prevents iOS auto-zoom on focus — must be ≥16px).
Focus state: 2px ring in `--color-ring`, offset 2px.
Error state: 1px border in `--color-destructive` + error message below.
Placeholder: `--color-muted`.

### Form Field (label + input + error)

Gap between label and input: 8px.
Gap between input and error text: 4px.
Error text: 14px, weight 400, `--color-destructive`.

### Role Selector (Signup only)

Two toggle buttons side by side: "작가" (Artist) | "구매자" (Buyer).
Selected state: accent background, white text.
Unselected state: surface background, foreground text, border.
Width: equal split, full container width.
Height: 44px (touch target).
This is NOT a shadcn ToggleGroup — implement as two controlled buttons with
aria-pressed for accessibility.

### Alert (Error/Success)

Error alert: `--color-destructive-muted` background, `--color-destructive` text,
left border 4px solid `--color-destructive`.
Success alert: oklch(0.95 0.05 155) background (#F0FDF4), green text,
left border 4px solid oklch(0.55 0.18 155).
No icon required in Phase 1 (icon library available but not required here).

### Card (auth form container)

Background: `--color-surface`.
Border: 1px solid `--color-border`.
Border radius: 12px.
Padding: 32px on desktop, 24px on mobile.
Box shadow: none (flat gallery aesthetic).

## Interaction Contract

### Form Submission States

| State | Visual Indicator |
|-------|-----------------|
| Idle | Normal button, enabled |
| Submitting | Button disabled, spinner icon (lucide `Loader2` with `animate-spin`), "처리 중..." label |
| Success | Redirect (no success toast needed — page change is feedback) |
| Error | Alert component above form, button re-enabled |

### Validation Timing

- Validate on submit first (not on change or blur) to reduce Korean IME input friction
- After first submit attempt: validate on change for corrected fields only
- Password field: validate length (min 8 chars) only on submit, not on type

### Focus Management

- Auto-focus first field on page load (email input on login/signup)
- After error: focus first errored field
- After successful signup redirect: no explicit focus management needed (new page load)

### Redirect Behavior (AUTH-04)

| Scenario | Behavior |
|----------|----------|
| Logged-out user visits /artist/* | Redirect to /login (no 403, no flash of content) |
| Logged-out user visits /buyer/* | Redirect to /login |
| Buyer visits /artist/* | Redirect to /buyer (their home), no error page |
| Artist visits /buyer/* | Redirect to /artist (their home), no error page |
| Logged-in user visits /login or /signup | Redirect to role-appropriate home |

No "access denied" page is shown. Redirects are silent (proxy.ts handles before render).

## Accessibility Contract

Target: WCAG 2.2 AA. Source: Auto-chain default.

| Rule | Implementation |
|------|---------------|
| Contrast (text) | All text colors provide ≥4.5:1 ratio against their background |
| Contrast (large text ≥18px) | Display and heading sizes provide ≥3:1 ratio |
| Focus visible | All interactive elements have 2px ring, `--color-ring`, offset 2px |
| Target size | All buttons and inputs minimum 44px height |
| Labels | All inputs have explicit `<label>` with `htmlFor` — no placeholder-only labels |
| Error announcement | Form errors use `role="alert"` or `aria-live="assertive"` |
| Role selector | `aria-pressed` on each role toggle button |
| Submit loading | `aria-disabled="true"` + `aria-label="처리 중..."` during submission |
| Heading hierarchy | h1 on page heading, no skipped levels |
| Language | `<html lang="ko">` on root layout |
